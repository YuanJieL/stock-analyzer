📊 Layer 1：基本面分析

判斷「這家公司值得買嗎」— 從財報評估公司長期內在價值

EPS成長率
≥40%=100分 / ≥25%=80分 / ≥10%=60分 / 衰退=10分
ROE股東報酬率
≥25%=100分 / ≥18%=80分 / ≥12%=60分
P/E本益比
越低越好：≤15=100分 / ≤20=80分 / ≤30=60分 / ≤45=40分
P/B淨值比
越低越接近淨資產：≤1.5=100 / ≤2.5=80 / ≤4=60
現金殖利率
≥5%=100分 / ≥3.5%=80分 / ≥2%=60分
負債比率
越低越穩健：≤30%=100 / ≤45%=80 / ≤60%=60 / ≤75%=40
營收成長率
≥35%=100分 / ≥20%=80分 / ≥10%=60分
📡 資料來源：公開資訊觀測站財報API、月營收公告（每月10日後更新）
📈 Layer 2：技術面分析

判斷「何時買賣最有利」— 分析K線、均線、動能指標找進出場時機

趨勢方向
站上MA20且MA60=上升(100) / 只站MA20=盤整(55) / 跌破=下降(20)
KD隨機指標
K<30超賣買點=90分 / K<50=75 / K<70=55 / K>70過熱=30分
MACD
黃金交叉=100 / 翻多=85 / 多頭=75 / 偏多=65 / 持平=50 / 死叉=20
RSI強弱指標
<30超賣=90分 / 30~50=75 / 50~65=60 / 65~80=40 / >80超買=15
成交量
大量/放量=90（趨勢確認） / 平穩=65 / 縮量=35（需謹慎）
📡 資料來源：Yahoo Finance OHLCV，指標自行公式計算（MA/KD/MACD/RSI）
🔮 Layer 3：籌碼面分析

判斷「誰在買賣，方向跟不跟」— 追蹤大戶法人動向，外資投信同步買超是最強信號

外資連買天數（權重35%）
≥5天=100 / ≥3天=80 / ≥1天=60 / 賣超=10分（最重要指標）
投信連買天數（權重20%）
≥3天=100 / ≥1天=75 / -1天=50 / 持續賣=20分
自營商淨買超（權重10%）
>500張=80 / >0=60 / 賣超=40（短線參考指標）
大戶持股變化（權重20%）
增加=85（籌碼集中看好） / 減少=45（需注意）
融資水位（權重15%）
低=90（健康） / 中=60 / 高=30（散戶過熱，風險信號）
📡 資料來源：證交所TWSE OpenAPI三大法人（免費官方API）、集保結算所大戶持股
